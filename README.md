# Инструмент визуализации графа зависимостей (Вариант 31)

## Общее описание
Программа на Python, которая строит граф зависимостей для пакетов (на примере Rust/Cargo) и выводит его в разных форматах. Работает в консоли (CLI).

## Функции и настройки
Настройки хранятся в файле `config.ini` (секция `[Settings]`):
- `package_name` — имя анализируемого пакета
- `repo_url` — путь к файлу тестового репозитория
- `test_mode` — режим тестирования (true/false)
- `version` — версия пакета
- `output_file` — имя файла для сохранения SVG
- `max_depth` — максимальная глубина анализа
- `filter_substring` — подстрока для фильтрации пакетов
- `ascii_tree` — вывод в виде ASCII-дерева (true/false)

3. Выполните команду:

python main.py
